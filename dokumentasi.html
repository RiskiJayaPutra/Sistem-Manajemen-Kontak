Instalasi Fitur Cara Penggunaan Keamanan Teknologi

Instalasi

Persyaratan Sistem

  • PHP 7.4 atau lebih tinggi
  • PDO SQLite extension
  • Web server (Apache/Nginx) atau PHP built-in server
  • Browser modern

Langkah Instalasi

  1. Clone atau Download Repository 
    git clone <url-repository>
cd "Judul 4"
  2. Jalankan dengan PHP Built-in Server 
    php -S localhost:8000
  3. Buka Browser dan akses 
    http://localhost:8000/login.php
  4. Login dengan kredensial default
    • Username: RiskiJayaPutra
    • Password: iki123

Fitur Utama

Sistem Login

Autentikasi pengguna dengan session management yang aman

Tambah Kontak

Form lengkap dengan validasi untuk menambahkan kontak baru

Edit Kontak

Perbarui informasi kontak yang sudah tersimpan

Hapus Kontak

Menghapus kontak dari sistem

Pencarian

Cari kontak berdasarkan nama, telepon, atau email

Filter Kategori

Filter kontak berdasarkan kategori tertentu

Validasi

Validasi lengkap untuk nomor telepon, email, dan data lainnya

Cara Penggunaan

1 Menambah Kontak

  • Klik tombol "Tambah Kontak Baru" di halaman utama
  • Isi form dengan data kontak (nama, telepon wajib diisi)
  • Klik "Simpan Kontak"

2 Mencari Kontak

  • Gunakan kotak pencarian di bagian atas halaman
  • Ketik nama, nomor telepon, atau email yang dicari
  • Pilih kategori untuk memfilter hasil pencarian
  • Klik tombol "Cari"

3 Mengedit Kontak

  • Klik tombol "Edit" pada kartu kontak
  • Ubah informasi yang diperlukan
  • Klik "Simpan Perubahan"

4 Menghapus Kontak

  • Klik tombol "Hapus" pada kartu kontak
  • Konfirmasi penghapusan dengan klik "OK"
  • Kontak dan fotonya akan terhapus permanen

Fitur Keamanan

Password Hashing

Password di-hash menggunakan password_hash() dengan algoritma bcrypt

SQL Injection Protection

Menggunakan Prepared Statements untuk semua query database

XSS Protection

Semua output di-escape menggunakan htmlspecialchars()

Input Validation

Validasi lengkap untuk semua input pengguna di sisi server

File Upload Security

Validasi tipe file, ukuran maksimal, dan nama file yang aman
